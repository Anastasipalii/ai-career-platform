# AI Career Platform

AI-powered multilingual platform for generating resumes, cover letters, and LinkedIn profile optimization content.

## Overview

This project is being built with React, Next.js, VS Code, and AI-assisted development workflows using Cloud Code tools.

The goal is to help users create professional career documents faster with AI support and multilingual accessibility.

## Features

- AI-generated resumes
- AI-generated cover letters
- LinkedIn profile optimization
- Multilingual support
- Responsive modern UI
- AI-assisted workflows

## Tech Stack

- React
- Next.js
- TypeScript
- Tailwind CSS
- VS Code
- Cloud Code

## Project Status

Currently in active development.
